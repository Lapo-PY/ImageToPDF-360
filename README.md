## ✨ Features

| Feature | Descrizione |
|---|---|
| 🖼️ **Multi-formato** | Supporta PNG, JPG, JPEG e WEBP |
| 📄 **PDF multipagina** | Ogni immagine diventa una pagina del PDF |
| 🔄 **Drag & Drop reorder** | Riordina le pagine trascinando le anteprime |
| ⚙️ **Impostazioni avanzate** | Formato pagina, orientamento, margini, qualità |
| 📐 **Formati pagina** | A4, A3, Letter, Legal, Adatta all'immagine |
| 🌙 **Tema scuro / ☀️ chiaro** | Toggle con memoria locale, rileva preferenza sistema |
| 💧 **Liquid Glass UI** | Effetti vetro, blob animati, orbs fluttuanti |
| 🔒 **100% Privato** | Nessun upload — tutto elaborato nel browser |
| ⚡ **Zero dipendenze** | Solo jsPDF via CDN — nessun build tool necessario |
| 📱 **Responsive** | Ottimizzato per desktop, tablet e mobile |
